BIG SKRILLA OFFLINE WEBSITE — ANDROID

1. Extract this ZIP completely. Do not open index.html while it is still inside the ZIP.
2. Keep all five HTML files together in the same folder.
3. Open the extracted index.html using Chrome, Firefox, or another browser.
4. The navigation buttons open the other local HTML pages.

Everything is embedded for offline use, including racing fonts, loading sequence,
animated portrait smoke, images, CSS, JavaScript and rotating sphere.
