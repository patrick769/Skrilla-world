# Skrilla HQ

Official SKRILLA site. Home is a scroll-to-rotate circular gallery.

Cards currently use site art only:

- `IMG_0548.PNG` — artist photo
- Official YouTube thumbnails for Kata Kichwa, Siku Hizi, and Lawama

To add more cards, put images in `assets/` and copy a commented entry in the `ITEMS` array in `index.html`.

Open `index.html`, or from this folder:

```
python3 -m http.server 8080
```
